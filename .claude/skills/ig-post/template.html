3 / 10
關鍵觀察整題的核心

終點 = 完整終點 − 被刪段位移

不刪任何東西，從頭走到底：

U D R U R → (2, 1)

刪掉 "UR"，就少走一次 ↑ 和一次 →

(2, 1) − (1, 1) = (1, 0)

換個角度：站在完整終點看，
刪掉 "UR" 就是偏移 (−1, −1)。

6 / 10

7 / 10
程式碼題解：灵茶山艾府

核心只有一個迴圈

// 第一個視窗當基準 (0,0)，放進集合 set.add((long) n << 20 | n); int x = 0, y = 0; for (int i = k; i < n; i++) { char in = s.charAt(i); char out = s.charAt(i - k); x += DIRS[in][0] - DIRS[out][0]; y += DIRS[in][1] - DIRS[out][1]; set.add((long) (x + n) << 20 | (y + n)); } return set.size();

高亮兩行就是「加新的、減舊的」。

8 / 10
小技巧 · 易錯點複雜度 O(n − k)

三個細節別踩雷

1 為什麼第一個視窗是 (0,0)？
只看「相對第一個視窗」的差，是否重複的結果不變，連初始累加都省了。

2 座標要 + n
位移可能是負的，壓成 long 前先加 n，避免位元運算出錯。

3 算的是位移，不是終點
終點 = 完整終點 − 位移，兩者是一對一，用哪個去重都行。

9 / 10
總結定長滑窗三步

定長滑窗模板

① 入新元素進視窗
② 更新視窗滿了才記錄答案
③ 出舊元素離開

這題的「答案」就是位移，
丟進集合去重。
